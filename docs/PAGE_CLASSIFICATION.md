Every page is one of three states (requirement 30.1):

- **Functional** — the page is backed by a real control-plane route and does what it says.
- **Intentionally disabled** — the page renders, states plainly why it does nothing yet, and presents
  no control that accepts input without effect (requirement 30.3/30.4). The reason column below is the
  exact reason shown to the person on that page.
- **Removed** — the page no longer exists. Listed separately below rather than silently dropped from
  this artifact, so its removal stays visible in history.
